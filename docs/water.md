# 水面（Single Layer Water）

> 结论先行：源帧的水面就是 UE 的 **Single Layer Water（SLW）**，材质 shading model ID = 10。本项目没有重写水体，而是把源帧实测的散射、吸收、相位系数填进 UE 自带的 SLW，并用开关与原近似做同机位对比。**这是参数对齐 + 一次系数替换，不是水体算法重写。**

## 源证据

**识别** [事实]：源帧水面 PS 的 shading model ID = 10，与 UE `ShadingCommon.ush` 的 `SHADINGMODELID_SINGLELAYERWATER` 相同；`exp(-σt·d)`、`(1-T)·σs/σt`、Schlick 相位等公式与 `SingleLayerWaterShading.ush` / `ParticipatingMediaCommon.ush` 逐项对应。

**本帧主水面常数** [事实]

| 量 | 值 | 说明 |
| --- | --- | --- |
| 散射 σs | (3.01e-5, 8.32e-5, 1.0e-4) /cm | 等于颜色 (0.301, 0.832, 1.0) × 1e-4 |
| 吸收 σa | (1/60, 1/60, 1/60) /cm | 灰色，不偏色 |
| 相位 g | 0.5 | Schlick 相位 |
| F0 | ≈0.02 | 水面镜面反射率 |

一个容易误读的常量：水面前向光照常量里出现的 **1.38037 = 4.33657 / π**，是太阳色除以 π，不是"水色"。水体本身的颜色由 σs / σa 与光程决定。

**合成公式** [事实]（σt = σs + σa）：

```
T            = exp(-σt · d)                    // 透射率，d 为水深处
背景色       = 背景 × exp(-σt · d_top)         // 水底/水下物体先被吸收
散射项       = min((1 - T) · σs / σt, 1)       // 单次散射能量
相位         = Schlick(g)，k = 1.55g - 0.55g³
水体出射     = 散射项 × (太阳色 · 相位 + 0.25 · 环境色)
```

**波浪** [事实]：源帧的 FFT 结果只在像素着色器里当法线用，顶点着色器不做位移，因此 UE 现有的滚动法线贴图在结构上比加顶点波更接近源帧。

公式各段的对应关系：`exp(-σt·d)` 衰减背景（水底、水下物体），`1-T` 是水柱吸收掉的能量比例，`σs/σt` 把这部分能量中属于散射的比例取出，再乘相位与光照。源帧把环境项固定为 0.25，不是能量守恒推导出来的常数，按原值保留。

## UE 实现

1. **材质**：关卡水面本来就是 SLW（`M_WaterMain_SLW`）。复制为 `M_Water_Restore_SLW` + 实例 `MI_Water_Restore_SLW`，**只挂在本关卡的一片水面网格上**；另两片水用简单近似材质，没有动。
2. **参数组 `WW Restore (Water)`**：`MC_Scattering_1PerCm`、`MC_Absorption_1PerCm`、`MC_PhaseG`、`Enable_Water_Absorb`。SLW 的三个输入各接一个 `lerp(原值, 源值, Enable)`；`Enable=0` 时与原材质逐项相同。
3. **切换**：`ue_water_restore.py enable 0|1` 写实例参数，同时镜像到 MPC 的 `Enable_Water_Absorb`；`unassign` 换回原材质。一个材质最多引用 2 个 MPC，而水材质已被风时钟与水条件占满，所以开关做成实例参数。
4. **对比基线**：原 UE 近似为散射 0（引脚未接）、吸收 (0.005, 0.0025, 0.0015)、g = 0（引脚未接）；换成源值后吸收提高 3–11 倍且不带色。
5. **第二轮表面参数**：Specular 0.25（F0 0.02）、Roughness 0.03、WaveStrength 1.3、WaterOpacity 0。前两项有源依据；后两项是观感校准，标 [美术]。
6. **折射与反射**：折射穿模回退、水面 SSR 都走 UE 自带 SLW 路径，没有手写。

| 项 | 结果 |
| --- | --- |
| 编译 | 通过：PS 1146 → 1225 条指令（散射项接通后增加） |
| 开关响应 | 通过：岸边视角整片水变暗、偏灰；其他区域只有风/云动画噪声 |
| 反射结构 | 通过：建筑与紫藤倒影被波纹拉成竖条，看不到水底，与源帧结构一致 |
| 同机位观感 | 注意：源帧水面主要靠反射显亮，吸收项本身不是主要差距 |
| `Enable=0` 等价 | 通过：三项 SLW 输入逐项等于原材质值，开关关掉不改变原画面 |

## 与源的差异

1. **没有 FFT 海洋**，也没有 Gerstner：源帧 FFT 只提供法线、不做顶点位移，UE 滚动法线贴图已是同构近似；加顶点波反而偏离证据。水面起伏的细节频谱与源帧不同。
2. **折射回退与 SSR** 用 UE 自带实现，源帧的具体回退条件（穿模时切反射）没有逐项对齐。
3. **只改一片水**：另两片水仍用简单近似材质，水位/岸线交界处与源帧的一致性没有验证。
4. **水色偏棕**：源帧蓝绿、当前偏暖。倒影里反射的是偏暖的天空与建筑，根因在天空/调色而非吸收系数，随天空模块一起处理。
5. **能量尺度**：吸收系数按 1/cm 原样填入，没有做 UE 世界单位换算；关卡按同一世界坐标重建，据此推断源帧与 UE 水深同尺度 [推断]，未单独验证。
6. **表面参数后两项是观感校准**：Roughness 0.03、WaveStrength 1.3 没有源证据，标 [美术]。
7. **系数只对主水面是常量**：源帧最大那片水的同一套公式用的是运行时计算的系数，不是常量 [待确认]；当前填的是主水面实测值，另两片水没有对齐。
